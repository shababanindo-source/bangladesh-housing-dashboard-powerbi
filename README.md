# Bangladesh Housing Market Dashboard (Power BI)

Interactive Power BI dashboard analysing residential housing market data across major cities in Bangladesh.

![Dashboard overview](images/dashboard-overview.png)
<!-- Add a screenshot named dashboard-overview.png inside an images/ folder -->

## Features
- **Price analytics:** average, minimum and maximum prices by location.
- **Property characteristics:** distribution of bedrooms, bathrooms, floors and area (sqft).
- **City comparisons:** filled maps for city-level comparison.
- **Interactivity:** slicers for location, features and availability.
- **Visuals:** KPI cards, gauges, donut and combination charts.

## Process
1. Cleaned and shaped the raw data in **Power Query**.
2. Built the **data model**.
3. Wrote **DAX** measures for dynamic aggregations.
4. Designed the report pages for easy exploration.

## Tools
Power BI Desktop · Power Query · DAX · Data modelling
